## Live replay

The verifier independently decodes every CRC-protected native result and
recomputes corrected distances, valid/comparable/changed masks, threshold counts,
classification and expected GPIO state. Detailed scene data and JSON summaries
remain under ignored `Phase06/validation/local/`.

The first verifier attempt exposed a host reply-handling bug: it consumed the
trailing configuration from `SELFTEST` as the response to a subsequent `CONFIG`
command. The verifier now drains the complete diagnostic response before sending
configuration commands. This required no firmware change.

The repeated run independently verified **65 consecutive real sensor frames**:

- Mean period **505,781 µs**, **1.977 fps**, within the 2 fps ±5% acceptance band.
- Minimum/maximum interval **503,998 / 506,002 µs**.
- **22 moving**, **42 static** and one baseline frame; no insufficient comparisons.
- Minimum **58 valid zones**, maximum **55 changed zones**.
- All masks, counts, motion states and GPIO readbacks agreed with native-packet
  replay. Seven real-sensor motion-on transitions were observed.

**The complete live acceptance run did not pass:** the USB stream stopped after
frame 66 (the observation started at frame 2), before the requested 120 frames.
There was no preceding firmware error or frame gap in the captured data. The
device remains enumerated as COM12 but responds neither to console commands nor
to esptool's normal/USB reset handshakes. The cause is not yet established.
The user confirmed the LED **continued reacting to movement** during the USB
failure, then reconnected the cable. This distinguishes the observed communication
failure from a demonstrated halt of the motion monitor. A repeated live run is
in progress.

## Physical observation

The user confirmed that moving a real hand/object makes the red LED turn on,
and holding still turns it off. This is separate from the synthetic GPIO test.
Range performance at 11 m, noise/false-positive characterization and current
consumption are outside this short validation.

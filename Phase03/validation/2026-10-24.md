Every packet passed per-block CRC/length checks, its original acquisition CRC32,
and the original whole-set CRC32. The independent decoder verified native type,
layout, lengths, EOF, status, consecutive packet numbers and focal planes. All
30 groups also passed a separate check that T0, T1 and result integration
timestamps match. The decoder preserves all four reference channels in each
histogram packet and maps the left/right half-fields to 64 unique coordinates.

Every SD CSV was independently parsed for 64 ordered zones, raw units, clock
correction and validity. Distances and SNR agreed with the associated native
result packet; timestamps, native frame numbers and histogram CRC metadata
matched the captured packets. Session/configuration JSON matched the device.

An initial short run exposed a truncated USB diagnostic line. The final firmware
uses a 4 KiB USB transmit buffer and a bounded 1-second write timeout; the host
also reports a specific truncated-diagnostic error. The final 30-set run above
passed with complete diagnostics and exports. No long endurance run was used.

After export the verifier resumed acquisition and received
`ready=1 recording=1 saved=33 next=34 rejected=0 gaps=0 io_errors=0`.

remain later work. No independent host ranging algorithm or endurance claim
